## 파이썬 학습 내용
* `print()`를 사용해 콘솔에 안내 문구와 퀴즈 결과를 출력하는 방법을 익혔습니다.
* `input()`으로 사용자 입력을 받고, 입력값에 따라 프로그램이 동작하도록 구성했습니다.
* 변수에 퀴즈 내용, 선택지, 점수 등 필요한 값을 저장했습니다.
* 문자열(`str`), 정수(`int`), 리스트(`list`), 딕셔너리(`dict`)의 기본 사용법을 익혔습니다.
* 리스트에 여러 선택지를 담고, 인덱스로 원하는 선택지를 조회했습니다.
* `for` 반복문으로 여러 퀴즈와 선택지를 차례대로 처리했습니다.
* `enumerate()`를 이용해 선택지의 순번과 내용을 함께 출력했습니다.
* `if`, `elif`, `else` 조건문으로 메뉴 선택과 정답 여부를 판단했습니다.
* `while` 반복문을 이용해 메뉴를 반복해서 보여주는 흐름을 만들었습니다.
* `range()`를 활용해 정해진 횟수만큼 반복하는 방법을 익혔습니다.
* f-string으로 변수 값을 포함한 안내 문구를 읽기 쉽게 작성했습니다.
* 함수를 사용하면 반복되는 동작을 이름 붙여 나누어 관리할 수 있음을 배웠습니다.
* 클래스로 퀴즈와 게임의 데이터 및 동작을 한곳에 묶는 방법을 익혔습니다.
* `__init__()`에서 객체가 생성될 때 필요한 초기 데이터를 설정했습니다.
* `self`를 통해 객체마다 다른 질문, 선택지, 점수를 관리했습니다.
* 모듈을 파일별로 나누고 `import`로 필요한 클래스와 기능을 가져왔습니다.
* `try`와 `except`로 잘못된 입력이나 입력 중단 상황에 대응했습니다.
* `with open()`을 사용해 파일을 안전하게 열고 닫는 방법을 배웠습니다.
* `json.load()`와 `json.dump()`로 파이썬 데이터를 JSON 파일에서 읽고 저장했습니다.
* 프로그램의 메모리 데이터와 파일 데이터를 맞춰 저장해야 변경 사항이 유지됨을 이해했습니다.
